# 页边伴读（0.18.0）

PDF 工具栏点击“伴读”，打开可拖动、可收起的小对话框。先“开始备课”，完成后“下一重点”。更多菜单包含暂停、自动带读、返回、本页全部和留出页边。显示空间不足时页边卡片折叠为编号，可通过留出页边调整原始 PDF 缩放。

伴读与现有侧栏共享同一完整 Codex/ACP 对话、模型、工作目录、工具、历史和权限。可直接要求查资料、调用工具、更新 Zotero LLM Wiki；这不是独立翻译会话。权限确认在“完整对话”中处理。顶部额度沿用现有账号查询，可点击刷新；API 模式或查询失败不伪造剩余百分比。翻译模型和聊天设置均未被本功能更改。

备课通过完整 Agent 的工具完成，要求分批读取全篇、核查关键图表公式、关联已有 Wiki，输出工作目录 `.zotero-companion/<libraryID>-<attachmentKey>.json`。文件原子替换；PDF 标识/大小/修改时间形成版本指纹。插件校验结构和模型报告的页码覆盖，覆盖全部页且有有效重点才允许教学。覆盖报告不是独立审计，也不保证模型已完全理解。无法读清的图表/公式应记录为待核查。扫描件需要文字识别才能可靠定位引句。

每个重点使用指定页的唯一原文引句定位；插件通过原生 PDF 字符坐标计算高亮，不接受模型像素坐标。结构化阅读模式通过原生 SDT 映射定位，不复用 PDF 像素位置。原文不能唯一匹配时不画猜测位置。页边卡片显示解释及 Zotero 链接，支持追问、定位、折叠。教学标记为插件显示层，不修改原 PDF 或覆盖已有原生注释；需要原生标注时可直接指挥同一 Codex 对话调用现有 Zotero 工具。

进度、当前重点与关联聊天 ID 保存在 Zotero 配置目录的 `zotero-chat/companion/`，重新打开可恢复。自动带读默认关闭；开启后每重点至少停留30秒，输入问题会暂停自动推进，后台标签和等待权限时不推进。关闭浮窗移除显示和监听，但不会擅自取消完整对话；需要停止备课时点击“暂停”或侧栏停止按钮。

视觉交互参考 assistant-ui 与 shadcn/AI Elements 的紧凑对话、输入框和折叠详情模式，由本地 Gecko DOM 实现；未接入其云服务，也未增加第二套 Agent runtime。

验证采用独立 Zotero 10.0.9 配置、生成 PDF、假 ACP 代理与测试备课材料：覆盖门控、原文定位、共享聊天历史、工具事件、正常权限拒绝、额度镜像、断点续读、缩放、原始/结构化阅读模式映射。未用真实模型进行整篇学术备课质量验证，未读取或改写用户论文作测试。当前不监听 Downloads 文件夹，也不自动后台处理新论文。
